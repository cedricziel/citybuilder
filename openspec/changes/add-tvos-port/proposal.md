## Why

Citybuilder ships on iPhone, iPad and Mac. The App Store Connect record and the fastlane match profiles already cover tvOS, but there is no Apple TV app. The game does not run there for three reasons. Its input assumes a finger or a pointer: map pan and zoom use `DragGesture` and `MagnificationGesture`, the scene reads touch locations, and the HUD uses `Stepper`, `Slider`, a rounded text-field style and `keyboardShortcut`, none of which tvOS offers. Apple TV also gives apps no writable persistent storage, so saves in Application Support cannot work. Now that iOS and Mac release through TestFlight, Apple TV is the remaining platform in the Universal Purchase.

**Depends on `add-cloudkit-client`** for the production CloudKit client and its list call.

## What Changes

- New `CitybuilderTV` app target in `project.yml` (tvOS 18, bundle id `com.cedricziel.citybuilder`, shared for Universal Purchase), with game-controller Info.plist keys and CloudKit and key-value-store entitlements. Every local package adds `.tvOS(.v18)`. CityCore code does not change.
- **Remote-driven map.** A reticle at the screen center marks the target tile. Swipes pan, clicks step one tile along the iso axes, select acts as a tap, and holding select opens the tile menu. The camera center stays on the map. On the map the game reads the remote directly, and the system focus engine owns it only in the HUD, so no press acts twice.
- **Building on tvOS.** Choosing a building starts placement at the reticle. The ghost follows the reticle, select confirms and starts the next one, and Back cancels. Roads are painted by toggling with select and stepping with clicks. Demolish removes one building per select and never paints.
- **HUD focus and Back.** Play/Pause moves focus between the map and the HUD. Back steps out one level at a time and ends at the pause menu. On the title screen, Back is left to the system, which returns to the Home screen.
- **Zoom:** HUD buttons, holding Play/Pause cycles three zoom levels, and controller triggers.
- **Game controllers:** stick, D-pad, A, B, Y, triggers and Menu map onto the same actions.
- **HUD and controls:** a TV HUD layout inside the system safe area. On tvOS only, −/+ steppers replace `Stepper` and `Slider`, `keyboardShortcut` is compiled out, and credits show their links as text.
- **Saves on tvOS** live in Caches and are uploaded to iCloud after every write. At launch, saves that are missing locally are restored. With no iCloud account, the title screen shows a notice that the game cannot dismiss.
- **Layered tvOS app icon and Top Shelf images**, generated by extending `scripts/generate-app-icon.swift`.
- **CI and release.** The `build (CitybuilderTV)` CI job and `make build` support land in the first milestone. The Fastfile gains a tvOS lane under fastlane's `:appletvos` platform, and `release-please.yml` gains a `tvos` TestFlight row. Testing stays internal only.

## Capabilities

### New Capabilities

- `tv-remote-controls`: how the Siri Remote and game controllers drive the reticle, panning, zoom, selection, placement, road painting, demolition, HUD focus and the Back button on Apple TV.

### Modified Capabilities

- `platform-shells`:
  - Universal platform support adds Apple TV.
  - Adaptive HUD per idiom gains the Apple TV layout.
  - Handoff is scoped to iPhone, iPad and Mac.
  - The audio session and interruption requirements cover tvOS.
  - Settings value controls become steppers on Apple TV.
  - The tool strip gains Apple TV hints.
- `rendering-2_5d`:
  - Input mapping adds the remote and controllers.
  - Tap suppression during pending placement and confirm-before-place cover Apple TV.
- `persistence-save-load`: Save location gains the Apple TV caches path.
- `icloud-sync`:
  - The no-account behaviour on Apple TV is a title-screen notice.
  - Last-write-wins states that restoring a missing local copy is not an overwrite.
  - A new requirement keeps Apple TV saves in iCloud.

## Impact

- **project.yml / Apps/**: the `CitybuilderTV` target, a `tvOS: "18.0"` deployment target, `Apps/CitybuilderTV/` (app entry, Info.plist with `GCSupportedGameControllers` and `GCSupportsControllerUserInteraction`, entitlements without iCloud Documents, layered icon asset catalog) and a scheme.
- **Packages/\*/Package.swift**: `.tvOS(.v18)` on all six packages. CityCore sources are unchanged, and `scripts/check-no-apple-ui-imports.sh` still gates them.
- **CityUI**:
  - a platform-neutral `RemoteInputMapper` with an injected clock, tested on the macOS host
  - a `GCEventViewController` host for the map
  - TV layout in `HUDLayout.make`, `SteppedValueControl`, and the reticle overlay
  - tvOS defaults for `confirmsBuildingPlacement`
  - camera-center clamping in the session
- **CityRender2D**: touch-location handling narrowed from `canImport(UIKit)` to `os(iOS)`.
- **CityAudio**: the session guards already include tvOS, so this needs tests only. The spatial and volume sliders get a stepped variant, and credit links show as text on tvOS.
- **CityPersistence**: a platform default for the save directory, and the tvOS upload, retry and restore coordinator, built on `add-cloudkit-client`.
- **CI / release / tooling**:
  - the `ci.yml` build matrix and `ci-ok`, and the tvOS simulator runtime on the runner
  - `Makefile` `build`
  - the verify skill's tvOS section
  - `fastlane/Fastfile`, the `release-please.yml` matrix, and the README
- **Determinism**: no simulation change. See design.md.
- **Tooling**: no new build-time tool dependency. GameController and CloudKit are Apple system frameworks.
